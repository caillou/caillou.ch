Unordered list

We can create unordered lists using hyphens, asterisks, or plus signs. For example:

  • First item
    • Nested item
    • Second nested item
  • Second item
  • Third item with bold and italic

As soon as we have enough space in the margins, we move the bullet points out.

Ordered list

  1. First item

  2. Second item
