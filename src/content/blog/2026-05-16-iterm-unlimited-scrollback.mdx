iTerm's default scrollback is 1000 lines. I've lost important output to it too
many times.

On [ATP 691](https://atp.fm/691),
[John Siracusa](https://mastodon.social/@siracusa) mentioned that macOS Terminal
has an unlimited setting. Turns out iTerm has the same thing, just buried.

<Figure src={settings} alt="iTerm settings, Profiles → Terminal tab, with Unlimited scrollback checkbox highlighted">
  Settings → Profiles → Terminal → Unlimited scrollback.
</Figure>
